# pey.sync

موتور همگام‌سازی دستی و backend-neutral برای مجموعه‌های `pey.storage.service` به فضای انتخابی کاربر (نسخه اول: مخزن گیت). این پکیج فعلاً همین‌جا incubate می‌شود (الگوی `pey.filesystem` در §۲۴ تصمیمات) و روز استخراج فقط جابه‌جا می‌شود.

## ساختار

- `manifest.json` — قرارداد معتبر افزونه.
- `index.js` — نقطه‌های ورود `prepare` و `activate` بنیان (فقط سیم‌کشی).
- `lib/` — سرویس، موتور تصمیم خالص، سریالایزرها، خطاها.
- `adapters/` — بک‌اندها (`git`) + قرارداد kind تازه.
- `tests/` — تست هر فایل سورس.
- `docs/requirements.md` — تنها منبع حقیقت پیاده‌سازی.
- `imp/` — طرح محلی؛ در گیت نیست.
- `CHANGELOG.md` — تاریخچه نسخه‌های این افزونه.

## وابستگی‌ها

- **لازم:** `pey.storage.service` — خواندن/نوشتن رکوردها و وضعیت/اعتبار موتور.
- **اختیاری:** هیچ‌کدام.

## همچنین ببینید

- `docs/reference.md` برای API کامل، ایونت‌ها، خطاها، پیکربندی، قواعد و محدودیت‌ها.
- `docs/decisions.md` §۳۴ (در ریشه پروژه) برای «چرا».
