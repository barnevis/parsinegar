# پارسی‌نگار (Parsinegar)

ویرایشگر فارسی Markdown بر پایهٔ معماری Pey — میزکار تک‌صفحه‌ای راست‌به‌چپ با ویرایش زنده، مدیریت چندسند و ذخیره‌سازی خودکار محلی. بدون ابزار ساخت: ماژول‌های ES بومی با importmap.

## امکانات

- **ویرایشگر زنده (CodeMirror 6):** نمای زنده تک‌پنلی با پنهان‌سازی نشان‌ها، تشخیص جهت هر خط (خودکار/راست‌به‌چپ/چپ‌به‌راست) با پین صریح، قلم وزیرمتن، ادامه خودکار بازبینه/فهرست/نقل‌قول، تورفتگی Tab، جابه‌جایی خط با Alt+Arrow و بستن خودکار جفت‌کاراکترها (شامل «» و بک‌تیک).
- **محتوای غنی:** هایلایت سینتکس بلوک‌های کد (۱۴ زبان) با دکمه رونوشت، رندر تصاویر راه‌دور (`http(s)`) با fallback به alt، چک‌باکس‌های تسک با کلیک، و هایلایت `==متن==`.
- **جست‌وجو و جایگزینی در همین سند:** دراپ‌دان ته منوبار با شمارنده، پرچم‌های حساسیت/کلمه کامل/باقاعده/فقط در انتخاب و جایگزینی تکی/همه؛ میان‌برهای `Ctrl+F` و `Ctrl+Shift+F` مستقل از چیدمان صفحه‌کلید.
- **حالت فقط-خواندن:** قفل هر سند (ذخیره‌شونده) از منوی پرونده، دکمه تاگل منوبار یا جفت حالت خواندن/نوشتن منوی نمایش؛ اسناد داخلی پروژه (راهنما، تاریخچه تغییرات، درباره) همیشه فقط-خواندن‌اند.
- **مدیریت اسناد:** چندسند با autosave روی IndexedDB، فهرست فایل‌ها با چینش (نام/زمان ویرایش/زمان ساخت)، تغییر نام درون‌خطی، دانلود مارک‌داون، مودال ویژگی‌ها، حذف با تأیید و وارد کردن فایل `.md`.
- **ناوبری و وضعیت:** فهرست مطالب با scrollspy، نوار وضعیت زنده (نویسه/حرف/واژه/خط/حجم با ارقام فارسی) و نشان قفل.
- **شخصی‌سازی:** چهار پوسته (روشن/تیره/دستگاه/سپیا)، جهت متن و اندازه قلم (۱۲ تا ۲۴) با ترجیحات پایدار.

## اجرا

```sh
npm install
npm start     # static server روی ریشهٔ پروژه، سپس باز کردن آدرس اعلام‌شده
```

نیازمندی: Node نسخه ۲۰ یا بالاتر. سرور باید ریشهٔ پروژه را سرو کند تا `node_modules/` (برای importmap) و `bootstrap.json` در دسترس باشند. `npm start` از `--single` استفاده می‌کند تا مسیرهای SPA مثل `/not-found` هم به `index.html` برگردند.

Pey و افزونه‌های آن (`@pey/core`، `pey.router`، `pey.webui`) وابستگی‌اند و سورس آن‌ها در این مخزن قرار نمی‌گیرد — مستقیم از GitHub نصب می‌شوند.

## آزمون

```sh
npm test
```

سوئیت با `node:test` و `jsdom` اجرا می‌شود (تست‌های سطح اپ در `tests/` و تست‌های UI در `src/`) و منطق خالص، کنترلر ادیتور با CodeMirror واقعی و جریان‌های صفحه را پوشش می‌دهد.

## ساختار

```text
parsinegar/
├── ABOUT.md            # درباره (سند داخلی فقط-خواندن در اپ)
├── CHANGELOG.md        # تاریخچه تغییرات (سند داخلی فقط-خواندن در اپ)
├── src/app/            # Runtime Host (ConfigSource / EnvSource / ModuleLoader + core.start)
├── src/ui/             # رابط کاربری روی pey.webui (صفحات، کامپوننت‌ها، هلپرها + تست‌ها)
├── src/plugins/app/           # افزونهٔ اختصاصی پارسی‌نگار (مالک مسیرها)
├── src/plugins/documents/     # مدیریت چندسند روی pey.storage (نسخه ۰.۳.۰)
├── src/plugins/settings/      # ترجیحات کاربر (پوسته، جهت، قلم) روی pey.storage
├── public/             # فایل‌های ایستا (فونت وزیرمتن، تم‌های سطح سند)
├── tests/              # آزمون‌های سطح اپ و یکپارچه‌سازی (node:test + jsdom)
├── docs/               # تصمیم‌ها (decisions.md)، مستندات UI و معماری
├── bootstrap.json      # تنها محل تعریف Adapterها، Pluginها و مسیر UI
└── index.html          # لودر Host + importmap (بدون ابزار ساخت)
```

## معماری

پروژه روی معماری Bonyan (نسخه ۰.۱۱) ساخته شده: منطق دامنه در افزونه‌هاست و UI فقط از مسیر سرویس‌ها با آن‌ها حرف می‌زند.

| افزونه | نوع | نسخه | مسئولیت |
|---|---|---|---|
| `parsinegar.documents` | product | ۰.۳.۰ | چندسند مارک‌داون (CRUD، عنوان یکتا، پرچم فقط-خواندن) روی `pey.storage` |
| `parsinegar.settings` | product | ۰.۲.۰ | ترجیحات کاربر (پوسته، جهت، قلم) روی `pey.storage` |
| `parsinegar.app` | — | ۰.۱.۰ | مالک مسیرهای اپ |

نکته‌ها:

- سند معماری: `docs/architecture.md`؛ تصمیم‌های ثبت‌شده: `docs/decisions.md`.
- این فایل، `CHANGELOG.md` و `ABOUT.md` داخل خود اپ هم از منوی «راهنما» به‌صورت سند فقط-خواندن باز می‌شوند.
- قراردادها: ESM بومی بدون باندلر، نام‌گذاری kebab-case، تست برای هر رفتار، بدون کامنت تزئینی در کد.
